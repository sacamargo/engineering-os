# Electrolinera Agency Scenario (Phase 8)

## User input (exact)

```text
Quiero crear una aplicación para una electrolinera para personas que tienen carros eléctricos.

Criterios de aceptación:
1. Debe funcionar en iOS y Android.
2. Debe poder visualizarse también en la web.
```

Do **not** add requirements to the prompt.

## Expected agency behavior

Discover (without inventing decisions):

- users / journeys / product needs (unknowns remain unknown)
- architecture, mobile, web, UX/UI, backend, security, testing, observability
- possible IoT/charging domain, payments uncertainty
- operational requirements
- missing capabilities / skills
- human-required domains where applicable

## Skill expectations

- UI UX PRO MAX may be a candidate (mobile+web UX) without being named
- Stop Slop may appear as transversal quality candidate
- Context Engineering may assemble planning context
- Marketing Skills only if marketing intent is actually present (should **not** be forced)

## Non-goals

- Do not invent payment provider
- Do not deploy
- Do not treat this as a codebase analysis task by default
