# Phase 8 Self-Refutation

| Attack | Verdict | Mitigation |
|---|---|---|
| Skill becomes hidden Capability | **Held** | Capabilities remain primary router; Skills after |
| Skill god-object | **Held** | Split modules; no monolith `skills.py` |
| Skill grants permissions | **Held** | Security checker + contract forbidden fields |
| Skill bypasses human approval | **Held** | No auto_approve; escalation codes |
| Keyword-only routing | **Held** | Structured signals + payment≠physical gate test |
| Silent copy without provenance | **Held** | Provenance required; unavailable flag |
| Fabricated missing source | **Held** | External packs marked unavailable |
| All projects select all Skills | **Held** | Scoring + Marketing not forced on electrolinera |
| Context dumps everything | **Held** | Budget + exclude + no full_repo_dump |
| Stop Slop universal reviewer | **Held** | Constraints + fail closed without source |
| UI UX becomes frontend engineering | **Held** | Constraints; no code execution grant |
| Marketing becomes PM/architecture | **Held** | Limitations + cannot_own_architecture |
| Agent claims Skill as evidence | **Held** | `record_skill_evidence` rejects authority claims |
| Composition as hidden DAG | **Held** | `implies_task_dependency` rejected |
| Version without reproducibility | **Held** | Evidence records skill_version |
| Unavailable silent fallback | **Held** | Unavailable list; not selected |
| Arbitrary conflict decisions | **Held** | Conflict arbitration escalates |
| Skill injects tool commands | **Held** | Security scan of workflow steps |
| Catalog requires Orchestrator edits | **Held** | Registry data-only registration test |
| Human domain wrongly automated | **Held** | NEEDS_SOURCE / NEEDS_HUMAN dispositions |

## Known residual risks

- Weak-signal routing can still over/under-select until more structured intent signals exist
- `unavailable` Skills still appear as candidates (intentional) — operators must read status
