# Phase 7 Scale Notes

| Scale | Status |
|---|---|
| 1 project local delivery | **Proven** |
| 10 projects | **Plausible** (serial local runs) |
| 100–1000 | **Unknown** — need artifact store + scheduler |
| 10_000 | **Unknown** — evidence growth + locking bottlenecks |

Bottlenecks expected: artifact storage, evidence volume, pipeline scheduling, cross-repo locks.
Do not claim cloud CI scale.
